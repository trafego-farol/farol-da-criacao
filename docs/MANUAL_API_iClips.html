Como atualizar o Farol direto do iClips

Passo a passo · sem exportar planilha · Vanguarda Martech

O que muda

Hoje você exporta duas planilhas do iClips, joga na pasta e roda o robô. Depois deste manual, você não exporta mais nada — o robô busca os dados sozinho e gera o dashboard.

Os números não mudam. Testei os dois caminhos com os dados de 13/08 e o resultado é idêntico: 233 peças de criação, 30 house, 48 redação, 26 vídeo, 10 tráfego, 179 dias de histórico e 21.275 peças no ano.

São 10 passos. Faça uma vez e nunca mais. Os passos 1 a 8 levam uns 20 minutos no total; do 9 em diante é o dia a dia.

1

Conferir se o Python está instalado

⏱ 1 min
  1. Aperte a tecla Windows, digite cmd e abra o Prompt de Comando.
  2. Digite py --version e aperte Enter.
O que deve acontecer: Aparece algo como Python 3.12.1.
Se der errado: Se disser que py não é reconhecido, o Python não está instalado. Baixe em python.org, e na tela de instalação marque a caixa “Add Python to PATH” antes de clicar em Install.
2

Achar a pasta do Farol

⏱ 1 min
  1. Abra o Explorador de Arquivos e vá até a pasta onde está o farol_pasta.py — a mesma que você usa hoje para colocar as planilhas.
  2. Clique na barra de endereço lá em cima e copie o caminho (algo como C:\Users\mauro\Farol).
O que deve acontecer: Você tem o caminho da pasta copiado.
Se der errado: Se não achar, procure por farol_pasta.py na busca do Windows.
3

Copiar os 3 arquivos novos para essa pasta

⏱ 2 min
  1. Baixe os arquivos que eu mandei e coloque dentro da pasta do Farol:
  2. farol_api.py — o que conversa com o iClips
  3. farol_pasta.py — substitui o antigo (o Windows vai perguntar se quer substituir: diga que sim)
  4. atualizar.bat — o atalho que faz tudo de uma vez
O que deve acontecer: Os três arquivos aparecem na pasta, junto com a pasta dados que já existe.
Se der errado: Se tiver medo de perder o antigo, renomeie o farol_pasta.py atual para farol_pasta_ANTIGO.py antes de copiar o novo.
4

Criar o arquivo da chave

⏱ 2 min
  1. Dentro da pasta do Farol, clique com o botão direito em um espaço vazio → Novo → Documento de Texto.
  2. Renomeie para api_key.txt (exatamente assim, tudo minúsculo).
  3. Abra o arquivo e cole a chave que já temos — gerada no iClips em Avatar → Chave de API.
  4. A chave tem que ficar em uma linha só, sem aspas, sem espaço antes ou depois.
  5. Salve e feche.
O que deve acontecer: O arquivo api_key.txt existe na pasta e tem só a chave dentro.
Se der errado: Se o Windows estiver escondendo as extensões, o arquivo pode ter virado api_key.txt.txt. Para conferir: no Explorador, aba Exibir → marque Extensões de nomes de arquivos.
5

Primeiro teste — puxar os últimos 45 dias

⏱ 2 a 3 min
  1. No Explorador, com a pasta do Farol aberta, clique na barra de endereço, apague o que estiver escrito, digite cmd e aperte Enter. Abre o Prompt já na pasta certa.
  2. Digite py farol_api.py e aperte Enter.
  3. Ele vai imprimir as janelas de datas que está buscando. Deixe rodando — ele espera alguns segundos entre as chamadas de propósito, porque o iClips só permite 10 consultas por minuto.
O que deve acontecer: No final aparece um resumo com PAUTA, ATIVIDADES, quantos apontamentos foram marcados como refação e os departamentos encontrados. E dois arquivos novos dentro de dados\: api_pauta.json e api_atividades.json.
Se der errado: ERRO 401 = a chave está errada ou a agência não está no Plano PRO. Confira se colou a chave inteira, sem espaços.
Nada retornado = amplie o período (veja o passo 6).
6

Carga histórica — uma única vez

⏱ 5 a 15 min
  1. Ainda no Prompt, digite:
  2. py farol_api.py 2026-01-01
  3. Isso traz o ano inteiro. Vai demorar: o iClips permite 31 dias por consulta e 10 consultas por minuto, então o script espera sozinho entre elas.
  4. Não feche a janela. Pode deixar rodando e ir tomar um café.
O que deve acontecer: Termina imprimindo o total de peças e apontamentos de todo o ano.
Se der errado: Se aparecer [limite de taxa] aguardando 30s, está tudo certo — é o script se comportando. Só esperar.
7

Gerar o dashboard

⏱ 1 min
  1. Ainda no Prompt, digite py farol_pasta.py e aperte Enter.
O que deve acontecer: Aparece a linha de sempre, mas agora dizendo fonte: api_pauta.json em vez do nome da planilha. E o index.html é gerado normalmente.
Se der errado: Se ainda disser fonte: lista_pecas.xlsx, os arquivos api_*.json não foram criados. Volte ao passo 5.
8

Conferir se os números batem

⏱ 3 min
  1. Abra o index.html que acabou de ser gerado.
  2. Compare com o dashboard de hoje: peças na pauta, entregues no dia e dias de histórico (no gráfico do ano).
  3. Se bater, deu certo. Se não bater, me manda o resumo que o script imprimiu que eu confiro.
O que deve acontecer: Os números são os mesmos de antes. A fonte mudou, o resultado não.
Se der errado: Se o histórico do ano tiver encolhido, é porque os relatorio*.xls antigos foram apagados da pasta dados\. Não apague esses arquivos — eles cobrem os dias que a API ainda não trouxe.
9

Usar no dia a dia

⏱ a partir de agora
  1. Daqui pra frente, para atualizar o dashboard: clique duas vezes no atualizar.bat.
  2. Ele puxa do iClips e gera o index.html sozinho.
  3. Você não exporta mais planilha nenhuma.
O que deve acontecer: Uma janela preta abre, mostra o progresso e no fim escreve Pronto.
Se der errado: Se a janela fechar rápido demais e você não conseguir ler, abra pelo Prompt: atualizar.bat.
10

Deixar automático (opcional)

⏱ 5 min
  1. Se hoje você já usa o Agendador de Tarefas do Windows para rodar o farol_pasta.py a cada 30 minutos:
  2. Abra o Agendador, encontre a tarefa do Farol, vá em Propriedades → aba Ações → Editar.
  3. Troque o programa para o atualizar.bat (caminho completo).
  4. Salve. Pronto: o dashboard passa a se atualizar sozinho, direto do iClips.
O que deve acontecer: A tarefa roda no horário e o site fica atualizado sem ninguém mexer.
Se der errado: Se você ainda não tem essa tarefa agendada, pule este passo — o clique duplo no atualizar.bat já resolve.

Resumo dos comandos

  • py farol_api.py — puxa os últimos 45 dias
  • py farol_api.py 2026-01-01 — puxa desde janeiro (carga histórica, uma vez só)
  • py farol_pasta.py — gera o index.html
  • atualizar.bat — faz os dois de uma vez (é o que você vai usar todo dia)
Três coisas para não esquecer.
1. O api_key.txt fica só na sua máquina. Ele nunca sobe para o Netlify — lá só vai o index.html.
2. Não apague os relatorio*.xls da pasta dados\. Eles seguram o histórico dos dias que a API ainda não trouxe.
3. O farol_api.py só faz leitura, num endpoint só. Ele não cria, não altera e não apaga nada no iClips, e não lê nada financeiro.
